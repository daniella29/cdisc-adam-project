# Getting the data

The data is from the CDISC pilot project and is not stored in this repository.

1. Download or clone: https://github.com/cdisc-org/sdtm-adam-pilot-project
2. From `updated-pilot-submission-package/900172/m5/datasets/cdiscpilot01/`, copy:
   - SDTM files from `tabulations/sdtm/` (e.g. `dm.xpt`, `ae.xpt`, `ex.xpt`) into `data/sdtm/`
   - ADaM files from `analysis/adam/datasets/` (e.g. `adsl.xpt`, `adae.xpt`) into `data/adam/`
3. Do not edit the files. Read them as they are.

Source: CDISC. Please read their terms of use in the repository README.
